# 🐺 LXR-SPIRITS — RedM Hunting Integration

This resource is wired to use real RedM hunting parts as ritual offerings.

```lua
Config.SpiritOfferings = {
    wolf   = { 'generic_animal_tooth', 'generic_animal_heart', 'ritual_sage_bundle' },
    eagle  = { 'provision_bird_feather_flight', 'ritual_sage_bundle' },
    bear   = { 'provision_bear_claw', 'provision_bear_heart', 'provision_meat_big_game' },
```

## Production RP Economy

- Hunters supply claws, hearts, teeth, feathers, antlers, and meat.
- Herbalists supply sage, dream root, blessed water, and moon water.
- Shamans perform ceremonies.
- Traders move rare animal parts into spiritual economy.
